## About Me

문제가 발생하면 원인을 끝까지 추적하여 해결하는 과정을 즐깁니다.

Spring Boot를 중심으로 백엔드 개발을 공부하며 MySQL, Docker, Redis, EC2를 활용해 실제 서비스를 설계하고 배포하고 있습니다.

단순히 기능을 구현하는 것보다 **왜 그렇게 설계해야 하는지**를 이해하는 것을 중요하게 생각하며, 프로젝트에서 경험한 트러블슈팅과 학습 내용을 꾸준히 블로그에 기록하며 성장하고 있습니다.
